# NumPy Matrix Operations

## Project Overview
This project demonstrates basic matrix operations using Python and NumPy, including matrix addition, subtraction, multiplication, and transpose.

## Objective
- Create two matrices using NumPy.
- Perform matrix addition and subtraction.
- Perform matrix multiplication using the `@` operator.
- Calculate the transpose of both matrices.
- Understand basic matrix operations used in machine learning.

## Technologies Used
- **Programming Language:** Python
- **Library:** NumPy
- **Platform:** Google Colab
- **Notebook:** Jupyter Notebook

## Matrices Used
```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
```

## Operations and Results

### Addition
```text
[[ 6  8]
 [10 12]]
```

### Subtraction
```text
[[-4 -4]
 [-4 -4]]
```

### Matrix Multiplication
```text
[[19 22]
 [43 50]]
```

### Transpose of Matrix A
```text
[[1 3]
 [2 4]]
```

### Transpose of Matrix B
```text
[[5 7]
 [6 8]]
```

## Matrix Multiplication Explanation
Matrix multiplication combines rows of the first matrix with columns of the second matrix. In NumPy, the `@` operator performs matrix multiplication.
